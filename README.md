# Circuit Flow

A small neon puzzle game for mobile browsers. Connect matching colored pipes
without crossing paths — every puzzle is randomly generated and always
solvable.

## Play

Open `index.html` in any browser, or visit the live GitHub Pages link once
this repo has Pages enabled. On a phone, use "Add to Home Screen" for a
full-screen, app-like experience.

## How to play

- Drag from a colored dot to its matching dot to connect the pipe.
- Pipes can't cross each other — route around.
- Drag back over your own pipe to shorten it, or grab it mid-way to redraw.
- Connect every color to win. Fill the whole board for a perfect score.
